# Component catalog

Every file in `html/` of the Tailwind Plus Application UI v4 library. Paths are
relative to that `html/` folder, which is what `tpui.py show <path>` expects.

Filenames are the whole description — `13-with-sortable-headings.html` is a table
with sortable headings. Numbers are Tailwind Plus's own ordering; gaps are normal
(some variants ship only in the React/Vue bundles).

Prefer `tpui.py search <terms>` when you know what you want and
`tpui.py list <category>` when you want one category. Read this file when you
want to see the whole shape of the library at once.
